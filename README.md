# AI Toolbox

Calvin's shared catalog of development tools, useful repositories, and implementation experience.

GitHub home: https://github.com/50thycal/ai-toolbox (public). Discovery instructions are included; setup in other AI environments has not been performed yet.

## Start here

- Agents: read [AGENTS.md](AGENTS.md), scan [INDEX.md](INDEX.md), then open only relevant entries.
- People: browse the index or add an entry using [templates/entry.yaml](templates/entry.yaml).
- New sessions: install the short [discovery rule](integrations/discovery-rule.md) once in each environment. See [setup instructions](docs/new-sessions.md).

## What belongs here

Tools that solve a concrete problem in our applications. Each entry records when to use it, limitations, evidence, lifecycle stage, and project-specific experience. Keep one canonical entry per tool. Reusable setup recipes can be added after a successful pilot.

## Maintenance

Update an entry after an evaluation or implementation, recording the actual outcome and date. Update the index alongside the entry. Preserve unsuccessful attempts and retirement reasons. Follow [lifecycle definitions](docs/lifecycle.md); favorable documentation alone does not establish Toolbox status.

The catalog is advisory. Existing project instructions, compatibility, and the user's current task determine whether a tool belongs in a particular project.
